# Exemples de messages

Déposez ici 5 à 10 vrais messages que vous avez écrits, un par fichier, nommés par type :

- `refus-1.md`
- `relance-1.md`
- `delegation-1.md`
- `rapport-1.md`
- `message-equipe-1.md`
- `reponse-candidat-1.md`

Retirez-en les noms, les chiffres et tout ce qui est sensible : ce qui compte ici, c'est la façon d'écrire, pas le contenu. Le skill `ma-voix` s'en sert pour imiter votre ton.
