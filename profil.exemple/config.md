# Configuration

Les skills lisent ce fichier avant toute chose. Gardez le format `clé : valeur`, une par ligne.

- langue : français
- tutoiement par défaut : non
- leaddeck : ~/LeadDeck
- classification autorisée : données internes non sensibles et sensibles ; jamais de données classifiées au-delà
- jour du tri : vendredi
- conservation candidats non retenus : 2 ans après le dernier contact

## Notes

- `leaddeck` : laissez vide si vous n'utilisez pas LeadDeck.
- `classification autorisée` : recopiez les niveaux de votre entreprise que vous avez le droit de traiter avec votre agent. Le companion refuse de stocker le reste.
- `conservation candidats non retenus` : la CNIL recommande 2 ans au plus après le dernier contact. Vérifiez la règle de votre entreprise avec votre DPO.
